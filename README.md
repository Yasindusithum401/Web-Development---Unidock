# Web-Development---Unidock

UniDock is a web based digital platform designed to help university students share, discover, and access academic resources efficiently. It allows students to manage study materials, organize daily tasks, set reminders, and collaborate in one centralized hub.

## Key Features
**Study Resource Upload:** Easily upload lecture notes, past papers, and study guides in PDF format.
**Smart Search:** Quickly locate study materials across different faculties and subjects.
**Interactive To-Do List:** Plan, track, and clear daily academic tasks.
**Reminders & Notes:** Create and manage important reminders for exams and assignment deadlines.
**User Authentication:** Built in modal components for User Login and Registration.
**Responsive Design:** Fully optimized for mobile, tablet, and desktop devices.

## Tech Stack & Dependencies
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Frameworks & Libraries:** 
* [Bootstrap 5.3.3](https://getbootstrap.com/) (Carousel & Layout components)
* [Font Awesome 6.7.2](https://fontawesome.com/) (Icons)
* [Google Material Symbols](https://fonts.google.com/icons) (UI Icons)
* [Google Fonts (Poppins)](https://fonts.google.com/)
